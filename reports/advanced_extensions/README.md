# BPhO 2026 advanced-extension reports

These ten short research records sit beside, rather than replace, the official competition submission. Each report states the new question, the added model, a numerical result, validation evidence, and a limitation. The figures and numerical values are generated from [`data/advanced_extensions.json`](../../data/advanced_extensions.json), the same deterministic artifact checked by `python3 -m submission.validate_advanced_extensions`.
