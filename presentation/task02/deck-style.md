# Task 2 Deck Style

- Canvas: 16:9 widescreen, 13.333 by 7.5 inches.
- Background: near-white `#F7FAFC`.
- Main text: dark slate `#243447`.
- Primary accent: blue `#0072B2`.
- Result accent: orange `#D55E00`.
- Supporting accent: green `#009E73`.
- Typeface: Arial for portability between macOS and Windows PowerPoint.
- Design: flat scientific layout, no gradients, no decorative illustration,
  and no unnecessary animation.
- Evidence: preserve the original generated plots without cropping data,
  changing axes, or editing labels.
- Accessibility: use high contrast, redundant text labels, and meaningful image
  alternative text; never rely on colour alone.
