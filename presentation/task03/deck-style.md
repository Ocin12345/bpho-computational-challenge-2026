# Task 3 Deck Style

- Canvas: 16:9 widescreen, 13.333 by 7.5 inches.
- Background: near-white `#F7FAFC`.
- Main text: dark slate `#243447`.
- Primary accent: blue `#0072B2`.
- Result accent: orange `#D55E00`.
- Supporting accent: green `#009E73`.
- Typeface: Arial for portability between macOS and Windows PowerPoint.
- Design: flat scientific layout, no gradients, decorative illustration, or
  unnecessary animation.
- Evidence: preserve the original validated figures without cropping data,
  changing axes, editing labels, or redrawing them with generative tools.
- Accessibility: use high contrast, redundant text labels, and meaningful
  image alternative text; never rely on colour alone.
- Consistency: use the same palette, typography, and footer treatment as the
  Task 2 presentation slide.
