Derivation

From contact to new velocities

The gas particle has mass m and velocity v; the tracer has mass M and velocity V. The unit normal n̂ points from the gas particle to the tracer.

  1. 1

    Project the approach onto the contact normal

    gn = ( V − v ) · n^ < 0

    A collision is resolved only when gn is negative. The tangential component is not changed.

  2. 2

    Apply equal and opposite impulses

    Δpm=−Jn , ΔpM=+Jn

    The two momentum changes cancel exactly, so total momentum is conserved before any algebra is done.

  3. 3

    Impose Newton's restitution law

    gn′ =−Cgn =gn +J ( 1m + 1M ) μ=mMm+M , J=−(1+C)μgn

    Here 0 ≤ C ≤ 1. Because gn < 0, the solved impulse magnitude J is positive.

  4. 4

    Update both velocities

    v′ = v−Jmn^ V′ = V+JMn^

    These are the values used by the simulation. They give g′n ≥ 0, so the bodies separate rather than collide again immediately.

  5. 5

    Repeat many impacts and measure diffusion

    vs = 3kBTm , τr = Knrvs ⟨ |X(t)−X(0)| 2 ⟩ ≈4Dt ⇒ D=14sMSD

    Random direction resets sustain the heat bath. In two dimensions, one quarter of the linear MSD slope is the diffusion coefficient.

Model scope

Assumptions disclosed

Browser visualization. This is a collision-driven stochastic heat bath, not full molecular dynamics. The Python reference analysis applies the same declared baseline and supplies the locked quantitative evidence above.

Hard discs
Small particles and the tracer have fixed circular radii.
Reflective enclosure
Particles rebound from a finite square boundary.
No gas–gas collisions
Only gas–tracer contacts receive collision impulses.
Direction reorientation
Scheduled random resets sustain the simplified heat bath.
Equal-speed heat bath
Gas particles share vs = √(3kBT/m).
Adjustable restitution
Contact response uses 0 ≤ C ≤ 1 and the shown normal impulse.

Repeated unequal impacts still drive an irregular tracer trajectory with no preferred direction, which is the Brownian mechanism this task is designed to demonstrate.
