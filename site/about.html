Origin

From Python to the browser.

This is my project for the 2026 British Physics Olympiad Computational Challenge. The ten tasks cover random motion, thermal radiation and quantum physics.

The Python programs produce numerical results and plots. The website lets you change the inputs and see what happens: increase the temperature of a black body, choose an atomic transition, or compare orbital shapes.

Each task has a different modelling question. A random walk needs an ensemble before its statistical pattern becomes clear. An atomic spectrum needs discrete energy levels. A useful display should make that difference visible, rather than treating every model as a moving particle.

You can explore the task pages in a browser without installing Python. To repeat the calculations, download the repository and follow the setup instructions. It includes the source, tests and saved data.

The Advanced Lab collects optional investigations and their reports. A separate research paper and problem sets are still in development; they are not part of the available materials below.

Method

How the models are checked.

The checks depend on the model. For random walks, the mean-square displacement should grow with the number of steps. For Compton scattering, energy and both components of momentum must balance. The particle-in-a-box calculation is compared with an independent finite-difference solution.

The task documentation records the equations, parameter ranges and approximations. Seeded runs make statistical results repeatable, while refinement checks show how selected calculations respond to a smaller time step or a finer grid.

Passing these checks shows agreement with the stated model. It does not establish that every approximation describes a real experiment.

Ten

The ten tasks.

The project is organised around ten computational challenges, progressing from statistical motion and thermal radiation to quantum systems and modern applications. Each task brings together the underlying theory, computational model, numerical results, visual evidence, and an explanation of the model's assumptions and limitations.

  1. 01Random walks
  2. 02Brownian motion
  3. 03Thermal radiation
  4. 04Photoelectric effect
  5. 05Atomic spectra
  6. 06Electron diffraction
  7. 07Particles in a box
  8. 08Quantum cryptography
  9. 09Compton scattering
  10. 10Hydrogenic orbitals

The optional investigations include finite barriers, spectral line broadening and a detector response for Compton scattering. Their reports explain which assumptions have changed from the core tasks.

Seeing

What the pictures mean.

An orbital picture shows probability density, not the path of an electron.

This distinction matters when a picture moves. Rotating an orbital changes the viewpoint; it does not evolve the quantum state. Likewise, the photoelectric trajectories illustrate the energy calculation without predicting the behaviour of a complete apparatus.

Read the axes, units and model notes alongside the plots. The coloured field on the opening page is decorative. The task pages identify the physical quantities their plots represent.

Change one parameter at a time to compare the model's prediction with what you expected.

Still curious

Try a calculation.

Start with a task you know, change a parameter and check the result against its equation. The repository's task folders show how the same quantities are calculated in Python.

If a result looks wrong, note the task, inputs and browser version when reporting it through the repository. Those details make it possible to repeat the problem.

The source and saved evidence are available so that you can inspect the calculations as well as the pictures.
